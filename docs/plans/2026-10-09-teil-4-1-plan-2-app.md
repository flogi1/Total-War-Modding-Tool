# Teil 4.1 Plan 2: Objekt-Ansicht in der App (Kontextmenü, Objekt-Tab, Links, Verlauf, veraltet, Session) – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rechtsklick auf eine Zeile einer DB-Tabelle (Pack oder Projekt) öffnet „Als Objekt anzeigen“: ein Tab mit dem Codeblock aus Plan 1, mit Links (Verlauf, Hover-Name, Shift-Klick für einen neuen Tab), Zuklappen großer Abschnitte, „Zur Zeile springen“, Markierung „veraltet“ nach Speichern oder Aktualisieren, Wiederherstellung nach dem Neustart, Farben für Vanilla, Mod und Projekt, und einer ausgelieferten Kategorie-Datei für Gebäude.

**Architecture:** Die App bekommt einen `ObjectsController` (UI-frei, Composition Root erzeugt ihn), der `TableStore`, `LocStore`, `ReferenceGraph` und `ObjectBuilder` pro Schema hält, die Ladereihenfolge aus Workspace und aktivem Projekt bildet, den Aufbau über `IOperationRunner` fährt, Objekt-Tabs öffnet und navigiert, Signaturen für „veraltet“ vergleicht und die Session-Daten liefert. `ObjectTabViewModel` (Tab-Art Objekt) hält Verlauf, Zustand und die gerenderten Zeilen; `ObjectLines` übersetzt die Spans der Library in anzeigbare Zeilen (reine Funktion). Die View ist ein `FlowDocument` in einem `ObjectBlockView` mit Hyperlinks; Code-behind nur Verdrahtung. Die Library `Objects` bekommt zwei kleine Ergänzungen (Eintragspfad pro Zeile, öffentlicher Anzeigename).

**Tech Stack:** C# 12, .NET 8, WPF, xUnit 2.9.2. Kein neues NuGet-Paket.

**Spec:** `docs/specs/2026-10-09-teil-4-1-objekt-ansicht.md`: 5.8 (App), 5.6 (Rendering: Übersetzung von `Title`, `Collapsed`, `Duplicate`, `OlderLayout`), 5.7 (Kategorie-Datei), 5.3 (Ladereihenfolge, Wurzel-Pack außerhalb), 2.3 (Erfolgskriterien), 7 (Fehlerfälle), 8 (Tests, App und manuelle Checkliste), 10 (Annahmen 1, 2, 5, 7). Projektregeln: `CLAUDE.md`.

**Branch:** `feature/teil-4-1-app` (von `master`, Stand `d172b4e` oder neuer). Baseline: voller Lauf vom 2026-10-09 mit 2233 Tests grün, 0 fehlgeschlagen, Build ohne Warnung.
